## `RegionNavigator` API surface

Constructor: `new RegionNavigator(system)` where `system` is the `CardDragDropSystem` instance. The navigator reaches the DOM via `system.playerBoard`, `system.playerHandCards()`, `system.orderableKeyboardCards()`, `system._findEndTurnControl()`, `system._findDrawControl()`.

Methods (each returns an element or `null`):

- `regionFor(element)` → `'hand' | 'field' | 'end-turn' | 'draw' | null`. Walks up from `element` via `.closest()` against, in order: `.playerScreen .deckHand .hand-scroll ul.hand li.cardContainer, .playerScreen .deckHand ul.hand li.cardContainer` (hand), `.playerScreen .lanes .cardContainer` (field), `.playerScreen .end-turn` (end-turn), `.playerScreen .deckHand .active-deck button.draw` (draw).
- `firstFieldCard()` → focusable field card element or `null`. Collects `.playerScreen .lanes .cardContainer[tabindex="0"]`, sorts by `getBoundingClientRect().top` ascending with tiebreak on `.left` ascending, returns the first.
- `handCardAt(slot)` → hand card element or `null`. `slot` is 1-based. Uses `system.orderableKeyboardCards()`. Returns `cards[slot - 1]` after clamping to range; `null` when the list is empty.
- `endTurnButton()` → `<button class="end-turn">` or `null` (delegates to `system._findEndTurnControl().button`).
- `drawButton()` → `<button class="draw">` or `null` (delegates to `system._findDrawControl().button`).

## `KeyboardSelectionControl.navigate(direction, fromElement)`

Signature: `navigate(direction, fromElement) → boolean`. `direction` is one of `'ArrowUp' | 'ArrowDown' | 'ArrowLeft' | 'ArrowRight'` (the raw `event.key` string). `fromElement` is any element (typically `document.activeElement`).

Steps:

1. `region = this.navigator.regionFor(fromElement)`. If `null`, return `false`.
2. Pick `target` by `(region, direction)`:
   - `(hand, ArrowUp)` → `this.navigator.firstFieldCard()`
   - `(hand, ArrowDown)` → `this.navigator.endTurnButton()`
   - `(field, ArrowUp)` → `this.navigator.endTurnButton()`
   - `(field, ArrowDown)` → `this.navigator.handCardAt(this.persistedHandSlot)`
   - `(end-turn, ArrowUp)` → `this.navigator.handCardAt(this.persistedHandSlot)`
   - `(end-turn, ArrowDown)` → `this.navigator.drawButton()`
   - `(draw, ArrowUp)` → `this.navigator.endTurnButton()`
   - `(draw, ArrowDown)` → `this.navigator.handCardAt(this.persistedHandSlot)`
3. If `target` is `null`, return `false`.
4. If `target` is a hand card: call `this.system.selectKeyboardCard(target, String(this.persistedHandSlot))` and return it. (This focuses the card and writes the hidden input via the persistence wiring.)
5. Otherwise: call `target.focus({ preventScroll: true })` and return `typeof target.focus === 'function'`.

`navigate` is called only from the new arrow-key branch in `onKeyboardKeyDown` — no other call sites.

## Reading `data-focused-hand-card` on first paint

`KeyboardSelectionControl` reads the dataset once in its constructor (called from `CardDragDropSystem.init()` right after the predicates are wired):

```
const raw = Number.parseInt(document.getElementById('turnLimits')?.dataset.focusedHandCard ?? '', 10);
this.persistedHandSlot = Number.isInteger(raw) && raw >= 1 ? raw : 1;
```

After every successful `selectKeyboardCard` call, `this.persistedHandSlot` is updated to `Number.parseInt(digitBuffer, 10)` so the next ArrowDown→hand / ArrowUp→hand lands on the slot the player just left. The update happens regardless of whether the call came from `selectOrderedCard`, `onHandCardClick`, `+ -` stepping, or `navigate`.

## `selectKeyboardCard` keeps the hidden input in sync

`selectKeyboardCard` (still public on `CardDragDropSystem`, delegating to `KeyboardSelectionControl`) writes the resolved ordinal to the end-turn form's hidden input whenever it installs a new hand-card selection:

```
const input = this.playerBoard?.closest('.playerScreen')
    ?.querySelector('form.cardActionForm input[name="focused_hand_card"]');
if (input) input.value = digitBuffer;
```

The write site sits after `clearKeyboardSelection()` and before the new `keyboardSelection` object is installed, so the hidden input reflects the about-to-be-focused card. The `digitBuffer` argument is the 1-based ordinal string passed into `selectKeyboardCard`:

- `navigate` always passes `String(this.persistedHandSlot)`.
- `selectOrderedCard`, `onHandCardClick`, and the `+ -` stepping path pass `String(index + 1)` (unchanged).

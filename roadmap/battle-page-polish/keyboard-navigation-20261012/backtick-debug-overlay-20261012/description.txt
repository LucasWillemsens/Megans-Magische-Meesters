Document and verify the backtick debug overlay. The source description notes the overlay is already in place; this goal is a verification + test-strengthening pass to lock the behavior in and make the player-facing nature explicit.

## Behavior

- Pressing the backtick key (`) toggles a shared CSS class on three `<p>` elements: the player deckHand counter, the enemy deckHand counter, and each lane indicator (`value | name`).
- The shared class positions the paragraphs as `position: absolute; background: white; z-index: 3;` so they appear as floating panels above the board content.
- The overlay is invisible by default.
- The overlay does not fire when the player is typing in a text input.
- The overlay is a player-facing UI feature — the toggled elements are real on-screen paragraphs, not a hidden dev console.

## Code locations

- `var/www/static/cardDragDrop.js` (or a new tiny `var/www/static/debugOverlay.js`) — the keydown listener that toggles the class.
- `var/www/static/cards.css` — the `.debug-overlay-visible` rule.

## Implementation notes

- Targets: `.playerScreen .deckHand > p` (first match), `.playerScreen .enemyDeckHand > p` (first match per enemy), `.playerScreen .lanes .lane > p` (each lane indicator).
- Trigger key: `event.key === '`'`, optionally also `'~'` for the shifted backtick on US keyboards.
- Guard against firing inside `input, textarea, select, [contenteditable]` elements.
- The class is purely additive — removing it restores the paragraph to its normal-flow position.

## Acceptance criteria

- Backtick toggles the `.debug-overlay-visible` class on the three target paragraphs.
- The CSS rule contains `position: absolute; background: white; z-index: 3;`.
- No toggle fires when focus is inside a text input.
- Toggled elements are real on-screen paragraphs, not hidden dev-only DOM.

## Notes

- Trigger key is the backtick (`) only. Shifted `~` is not accepted.
- The toggle key is not configurable. A future enhancement could expose this in settings.
- Discovery is strictly keyboard-only. A settings toggle / help tooltip would be a separate goal.

## Dependencies

- None. Standalone; can be landed first or last in the `keyboard-navigation-20261012/` order.

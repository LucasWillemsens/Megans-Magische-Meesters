The four player lanes are too narrow: at 56% field width with 14% horizontal padding on each side, only ~5 cards fit per row before the lane-stacking JS adds an overflow row. The field should be wider so each lane fits ~9 cards per row on a 1920px monitor.

## Behavior

- On a 1920×1080 monitor the four lanes span ~90% of the viewport width.
- Each lane fits at least 9 overlapping cards before overflow.
- On 4K and larger screens the field scales proportionally to ~90vw (no pixel cap).
- Mobile (`@media (max-width: 700px)`) is untouched.
- Both player and enemy fields are widened symmetrically.
- `LaneCardStacking.MAX_CARDS_PER_ROW` matches the new per-row capacity so overflow triggers correctly.
- The four lanes stay equal-width and equal-height; the lane indicator stays centred.

## Code locations

- `var/www/static/cards.css` — `ul.lanes` rule, `ul.cardRow li.cardContainer:nth-child(N)` rules, `ul.hologramRow .hologram:nth-child(N)` rules.
- `var/www/static/laneStacking.js` — `LaneCardStacking.MAX_CARDS_PER_ROW`.

## Implementation notes

- Replace `ul.lanes` `width: 56%`, `padding: 0 14%`, `gap: 2%` with `width: 90vw`, reduced side padding, and the tighter gap.
- Raise `MAX_CARDS_PER_ROW` to a value matching the new per-row capacity; add the missing `nth-child` rules in both `ul.cardRow li.cardContainer` and `ul.hologramRow .hologram` for the new max.
- The `overlapOffset` value stays the same; only `MAX_CARDS_PER_ROW` changes.

## Acceptance criteria

- 1920×1080: lanes span ~90vw.
- 4K and larger: lanes scale proportionally to ~90vw (no pixel cap).
- Narrow viewport (<700px): mobile block unchanged.
- Four lanes remain equal-width / equal-height.
- `MAX_CARDS_PER_ROW` matches the number of defined `nth-child` rules.

## Notes

- Width uses `90vw` with no pixel cap, so lanes scale proportionally on 4K and larger screens.
- `gap: 1.5%` (preferred over `2%`).
- Both `ul.cardRow li.cardContainer` and `ul.hologramRow .hologram` get the new `nth-child` rules so the hologram row stays symmetric with the card row at the new per-row capacity.

Show a brief "enemy is thinking" overlay when the player ends their turn, before the board reloads.

Summary: Add a CSS/JS overlay that appears on end_turn click, creating the illusion of the enemy taking their turn, then hides when the page reloads.

Implementation:
1. Modify `MMM/jinja2/MMM/battle/viewBoard.jinja2`:
   - Add a hidden overlay div at the end of the template with "Enemy is thinking..." text.
2. Create `var/www/static/enemyTurnOverlay.js`:
   - On end_turn button click, show the overlay with a fade-in animation.
   - The overlay stays visible until the page reloads (form submission handles this).
   - Add a simple pulsing/thinking animation to the enemy name.
3. Add CSS in `var/www/static/style.css` for `.enemy-turn-overlay`:
   - Semi-transparent backdrop, centered text, fade-in transition.
   - Pulsing animation on the enemy name text.
4. Link the JS file in `viewBoard.jinja2`.

Files to create:
- `var/www/static/enemyTurnOverlay.js`

Files to modify:
- `MMM/jinja2/MMM/battle/viewBoard.jinja2` (add overlay div + script tag)
- `var/www/static/style.css` (new .enemy-turn-overlay classes)

Acceptance criteria:
- Clicking "End turn" immediately shows an overlay with "Enemy is thinking..." message.
- The overlay has a pulsing animation on the enemy name.
- The overlay disappears when the page finishes reloading with the new board state.
- Overlay does not interfere with form submission.

Dependencies: None (can be done in parallel with other subgoals).

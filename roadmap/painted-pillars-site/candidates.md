# painted-pillars-site rule candidates

## Preserve user intent in roadmap descriptions
- **Pattern:** Agent-authored plans can drift from user intent by treating inferred scope, snapshot windows, page counts, or visual interpretations as agreed requirements.
- **Evidence:** PR #32 reviewer corrected the archive research scope and instructed one page per archived post, rather than the planned snapshot window and frozen four-page scope.
- **Proposed-rule:** Don't encode agent-derived scoping decisions as agreed specifications in roadmap descriptions; preserve user input and mark unresolved choices as open.

Make shuffleBoard return cards to the deck in a random order instead of queryset order so deck exhaustion shuffles stay fair.

Code locations:
- MMM/models.py — `BattleParticipant.shuffleBoard()`: iterates `boardCards` and `handCards` querysets and calls `state.shuffleBack()` in database order; the two querysets should be combined (fix the join filter or convert to a list) and the order randomised.

Implementation notes:
- `state.shuffleBack()` reinserts cards into the deck; insertion order currently determines draw order after a shuffle.
- Convert both querysets to a single list and `random.shuffle` it before calling `shuffleBack()` on each card.
- Related: done/game-mechanics/deck-exhaustion-shuffle covers when the shuffle triggers; this goal covers the fairness of the resulting order.

Acceptance criteria:
- Board and hand cards are interleaved in random order when shuffled back.
- Repeated shuffles do not produce a predictable draw sequence.

Make confirming a keyboard selection stage the same faceDown hologram as drag-and-drop
plays, focusable and click-to-flip while flips remain. Subgoal 3 of 3 of
`keyboard-selection-extensions/`; land last in the leaf.

Current state (`var/www/static/cardDragDrop.js`):
- `confirmKeyboardSelection()` keeps the face-up `.keyboard-preview` hologram, marks it
  `keyboard-staged`, then calls `_stagePlay(card, lane, hologram,
  preserveKeyboardPreview=true, selection)`.
- Drag plays (`onDropZoneDrop`) instead build a faceDown hologram via
  `_buildPlayHologram(card, laneValue)` whose non-preview branch adds `.faceDown` +
  `.back`, sets `inert` on any buttons found, and attaches a one-shot
  `onFaceDownCardClick(event, laneValue)` listener so clicking flips it face up.

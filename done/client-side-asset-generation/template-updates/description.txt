Update all templates that render card faces to show CSS playing card markup (from the cards.css framework) instead of the fallback placeholder image `1flubeltje.jpg` when `artSource == "static"`. The playing card rendering applies the rank class, suit class, rank span, and suit span on the `.card` element so the CSS framework generates the visual appearance.

## General pattern

Every card follows this pattern after the update:
```jinja2
<div class="card smallCard{% if card.artSource == "static" %} staticCard {{ card|playing_card_rank_class }} {{ card|playing_card_suit_class }}{% endif %}">
    {% if card.artSource == "static" %}
    <span class="rank">{{ card|playing_card_rank_display }}</span>
    <span class="suit">{{ card|playing_card_suit_display }}</span>
    {% else %}
    {% if card.artSource == "" %}
    <img class="fit-picture" src="{{ static('1flubeltje.jpg')}}" alt="no art of {{card.title}}" />
    {% else %}
    <img class="fit-picture" src="{{ static(card.artSource)}}" alt="art of {{card.title}}" />
    {% endif %}
    {% endif %}

    <div class="smallCardInfo">
        {% if card.artSource != "static" %}
        <p class="cardTitle">{{ card.title }}</p>
        {% endif %}
        <p class="cardType">
            {{["Intelligence","Speed","Visciousness","Resolve"][card.cardType]}}
        </p>
    </div>
</div>
```

Note the marker convention: **`artSource == "static"`** selects the CSS playing-card rendering (cards created by `add_deck_cards.py` use `artSource = "static"`). The empty string `""` remains the "no art" fallback and still renders `1flubeltje.jpg`. The `.smallCardInfo` title is hidden for static cards (the rank/suit are the identity) but the cardType line stays.

For the `.card` element to receive the CSS framework styles, it must be inside a container with class `.playingCards`. When a template section does NOT already have a `.playingCards` wrapper, one must be added as a parent div.

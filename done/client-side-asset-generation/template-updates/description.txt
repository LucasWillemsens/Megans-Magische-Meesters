Update all templates that render card faces to show CSS playing card markup (from the cards.css framework) instead of the fallback placeholder image `1flubeltje.jpg` when `artSource == ""`. The playing card rendering applies the rank class, suit class, rank span, and suit span on the `.card` element so the CSS framework generates the visual appearance.

## General pattern

Every card currently follows this pattern:
```jinja2
<div class="card smallCard">
    {% if card.artSource == "" %}
    <img class="fit-picture" src="{{ static('1flubeltje.jpg')}}" ... />
    {% else %}
    <img class="fit-picture" src="{{ static(card.artSource)}}" ... />
    {% endif %}
    <div class="smallCardInfo">
        <p>{{ card.title }}</p>
        <p class="cardType">TypeName</p>
    </div>
</div>
```

Replace with:
```jinja2
<div class="card smallCard{% if card.artSource == "" %} {{ card|playing_card_rank_class }} {{ card|playing_card_suit_class }}{% endif %}">
    {% if card.artSource == "" %}
    <span class="rank">{{ card|playing_card_rank_display }}</span>
    <span class="suit">{{ card|playing_card_suit_display }}</span>
    {% else %}
    <img class="fit-picture" src="{{ static(card.artSource)}}" ... />
    {% endif %}
    <div class="smallCardInfo">
        <p>{{ card.title }}</p>
        <p class="cardType">TypeName</p>
    </div>
</div>
```

The rank and suit classes go on the **same `.card` element** as the CSS framework expects (`.playingCards .card.rank-j.spades`). The rank and suit spans provide the top-left text labels; the CSS framework's `:after` pseudo-elements generate the large center symbols and the mirrored bottom-right rank.

For the `.card` element to receive the CSS framework styles, it must be inside a container with class `.playingCards`. When a template section does NOT already have a `.playingCards` wrapper, one must be added as a parent div.
